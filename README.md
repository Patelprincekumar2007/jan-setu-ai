## 1. Prototype Scope & Transparency Notice

NagrikLens AI is an institutional decision-support prototype built to demonstrate how citizen development requests can be consolidated, structured with Google Gemini, and grounded against verified open public datasets and knowledge evidence.

**Important Disclosure:**
- NagrikLens AI is a decision-support prototype.
- It is NOT an official government portal, grievance redressal system, or government-endorsed application.
- It does NOT claim official government affiliation, deployment, or partnership.

---

## 2. Information Separation Architecture

The platform strictly separates three classes of information:
1. **Citizen Data:** Development requests submitted by citizens (unverified requests).
2. **Public Source Data:** Verified open data from official portals (e.g. data.gov.in, Ministry of Jal Shakti) published under open government licenses (GODL).
3. **AI Interpretation:** Structured parameters, grounded summaries, and observations generated by Google Gemini models.

Public data is never presented as citizen submissions, and AI inferences are never presented as official government data.

### Retrieval & Grounding Workflow
```
[ 1. RETRIEVAL FLOW ]
Citizen Request (Text + Location + Category)
      ↓
Query Builder (Deterministic Query Formulation)
      ↓
Hybrid Retriever (Metadata Match Level + Multilingual FAISS Cosine Similarity)
      ↓
Ranked Verified Public Evidence (KnowledgeEvidence records with IDs)

[ 2. RAG / GROUNDED ANALYSIS FLOW ]
Structured Request Parameters + Verified Public Evidence
      ↓
Context Builder (Isolated User-Data Block + Prompt Injection Defenses)
      ↓
Google Gemini 2.5 Flash / Pro API
      ↓
Structured Grounded Analysis (Summary, Observations with Evidence ID Citations, Gaps, Data Limitations)
```

## 4. Public Data & Knowledge Layer (Phase 2 Step 3A - 3C-4)

### Verified Public Baseline Data
- **Dataset Title:** District-wise Rural Household Tap Water Coverage (JJM Baseline)
- **Dataset ID:** `ds-jjm-water-coverage-2024`
- **Source:** Open Government Data (OGD) Platform India / Ministry of Jal Shakti
- **Source URL:** https://data.gov.in/resource/district-wise-rural-drinking-water-supply-and-tap-connections
- **Publisher:** Department of Drinking Water and Sanitation, Ministry of Jal Shakti, Government of India
- **License:** Government Open Data License - India (GODL)
- **Geographic Scope:** National (District-Level)
- **Ingestion Status:** INGESTED (25 district baseline records with row-level provenance)

### Hybrid Retrieval (Step 3C-2C)
- Combines deterministic administrative filters (`state`, `district`, `category`) with multilingual vector search (`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`).
- **Deterministic Ranking Scheme:**
  1. `metadata_match_level` (3 = State+District+Category match, 2 = District+Category match, 1 = Category match, 0 = Semantic-only)
  2. `similarity_score` (Cosine similarity over L2-normalized vectors)
  3. `evidence_id` ascending (Deterministic tie-breaker)
- **Deduplication:** Merges results by `evidence_id` and tags provenance method (`hybrid`, `semantic`, or `metadata`).

### Citizen Request to Retrieval Pipeline (Step 3C-3)
- Automatically triggers upon citizen request creation.
- Dynamic query builder formats citizen narrative and structured parameters into a concise search query.
- Persists request-evidence links in `request_evidence_matches` table.
- Non-blocking: request creation succeeds even if retrieval or Gemini is temporarily unavailable.

### RAG & Grounded Analysis (Step 3C-4)
- Context builder places untrusted citizen input in isolated user-data blocks with strict anti-injection guardrails.
- Gemini is instructed to use only supplied evidence, never invent facts, and explicitly report evidence gaps.
- Returns validated `GroundedAnalysis` with evidence ID citations for every observation.
- Persists results in `request_analyses` table.

## 6. Quick Start & Local Setup Guide

### Prerequisites
- **Python:** 3.11 or higher
- **Node.js:** 18.x or higher (npm / pnpm / yarn)
- **Google Gemini API Key:** Access to Gemini 2.5 Flash / Pro via [Google AI Studio](https://aistudio.google.com/)

### 1. Repository Setup
```bash
git clone https://github.com/Patelprincekumar2007/jan-setu-ai.git
cd jan-setu-ai
```

### 2. Backend Setup
```bash
# Create and activate Python virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install backend dependencies
pip install -r backend/requirements.txt

# Configure environment variables
cp backend/.env.example backend/.env
# Edit backend/.env and add your GEMINI_API_KEY
```

**Run Backend Server:**
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
The FastAPI interactive documentation will be accessible at `http://localhost:8000/docs`.

### 3. Frontend Setup
```bash
# Navigate to frontend directory
cd frontend

# Install npm dependencies
npm install

# Start development server
npm run dev
```
The React frontend web application will be accessible at `http://localhost:3000`.

### 4. Running the Test Suite
```bash
# Execute full backend test suite with Pytest
pytest tests/ -v
```

## 7. API Endpoints

### Citizen Request APIs
- `POST /api/requests`: Submit a citizen development request (triggers Gemini extraction and hybrid retrieval).
- `GET /api/requests/{reference_id}`: Track submitted request by reference ID (`NL-YYYYMMDD-XXXXXX`).
- `GET /api/requests/{reference_id}/evidence`: Retrieve public evidence matches linked to a request.
- `POST /api/requests/{reference_id}/analysis`: Generate or view grounded RAG analysis for a request.

### Public Dataset APIs
- `GET /api/datasets`: List all registered public datasets with metadata, license, and ingestion status.
- `GET /api/datasets/{dataset_id}`: Get metadata for a specific dataset.
- `GET /api/datasets/{dataset_id}/records`: Get normalized civic metric records.

### Knowledge Retrieval Layer APIs
- `GET /api/knowledge/search`: Retrieve grounded knowledge evidence using deterministic metadata filtering.
- `GET /api/knowledge/semantic-search`: Retrieve grounded knowledge evidence using FAISS vector semantic similarity.
- `GET /api/knowledge/hybrid-search`: Retrieve grounded knowledge evidence using combined hybrid ranking.
- `GET /api/knowledge/status`: Check availability and freshness of the vector index.

### System
- `GET /health`: Basic health check (`{"status": "ok", "service": "nagriklens-ai-api"}`).

## 8. Known Limitations

1. **Current Public Data Coverage:** Currently includes 25 district baselines from Jal Jeevan Mission 2024.
2. **Vector Index:** FAISS IndexFlatIP runs locally as a fast prototype vector index.
3. **Similarity Scores:** Similarity score indicates semantic proximity, not real-world certainty or statistical confidence.
4. **Missing Evidence:** Lack of public records does not imply a citizen problem does not exist; gaps are explicitly identified.
5. **No Decision Automation:** Decision automation, priority scoring, hotspot detection, and automated dispatch are intentionally excluded from this phase.
